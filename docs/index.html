How to Use KtAstBridge Studio

          
Bidirectional Figma Auto Layout ↔ Kotlin AST ↔ Jetpack Compose Compiler

        

        
      


      

        

          
1. Compose (.kt) → Figma UI

          

            Paste or type any @Composable function in the left editor (or pick a preset). The lexer & AST parser unroll Modifier chains and render the live Figma Auto Layout frame on the right.
          

        

        

          
2. Figma UI → Compose (.kt)

          

            Click any layer on the Figma canvas (right pane) to edit its text, Auto Layout mode, color, padding, rotation, or scroll behavior—or paste Figma JSON in the center tab—and click Sync → Kotlin AST.
          

        

        

          
3. Inspect AST & Screen Sizes

          

            Click nodes in the center Kotlin AST Tree to inspect KtCallExpression arguments, or test Compact / Medium / Expanded widths and Portrait/Landscape rotation.
